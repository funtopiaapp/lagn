# Place data

`places.tsv` is derived from the GeoNames geographical database
(https://www.geonames.org/), files `cities15000` and `admin1CodesASCII`,
by `scripts/build_places.py`.

GeoNames data is licensed under the Creative Commons Attribution 4.0 License
(https://creativecommons.org/licenses/by/4.0/). The web app displays the
required attribution: "Place data © GeoNames (CC BY 4.0)".
